# Painel de Atendimento Gráfica Log — atualizações

Este repositório guarda **só os instaladores** do Painel de Atendimento da Gráfica Log.
O programa instalado nos computadores da gráfica confere este repositório ao abrir e a cada 20 minutos.
Quando encontra uma versão nova, ele se atualiza sozinho.

| Arquivo | Para que serve |
| --- | --- |
| `versao.json` | número da versão mais nova publicada |
| `Instalar-Painel-Grafica-Log.exe` | instalador dessa versão (também serve para instalar num computador novo) |

**Instalar num computador novo:** baixe o `Instalar-Painel-Grafica-Log.exe`, rode e entre com o usuário da pessoa.
